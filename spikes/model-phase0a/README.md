# Phase-0a model spike (archived)

Standalone proof (June 2026) that registries + a bipartite state/process DAG +
make/buy expansion + a greedy RCPSP scheduler can express the MVP dishes.
**Not imported by the app** — the shipping engine lives in `dist/kitchen_app.html`
(data in `data/*.json`). The ideas proven here are formalised in
`docs/bipartite-model.md`, `docs/scheduler.md` and `docs/walkthroughs.md`,
which supersede this code. Kept for reference; runnable via `npm test` inside
this folder.
